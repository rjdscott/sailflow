# How J/70 experts think about trim: grouping controls and feedback cues

- **Date:** 2026-08-25
- **Method:** Web research across 20 sources — sailmaker tuning guides (North, Quantum, Doyle, UK), North U trim theory, Sailing World / SailZing technique articles, and top-team interviews — synthesised into a by-sail-system panel design. Evidence strength flagged per claim.

## 2. Findings

### 2.1 Crew roles and control ownership

There is a **real contradiction here** and it matters for panel design.

**North Sails Speed Guide (S3)** — the most authoritative J/70-specific source:
- **Helm**: trims mainsail upwind, manages helm pressure + heel angle
- **Jib trimmer**: jib sheet + inhauler, jib telltales
- **Spinnaker trimmer**: kite, fore-aft weight when planing
- **Tactician/forward**: speed feedback ("netting out fast forward"), fleet

**Sailing World / Quantum (S5, S2)** — the more common club structure:
- **Main trimmer** owns mainsheet + traveller + backstay (and often tactics)
- **Helm** steers only, trims main *downwind*
- **Bow** owns vang, outhaul, cunningham, halyards

**Duncan's Worlds-winning team (S18)** splits main+tactics into one seat (Hardesty), jib into another (van Waay). Quantum (S2) puts the *tactician* on the main upwind — a third arrangement.

**Design implication:** ownership is fleet- and team-dependent, so **do not key the panel to crew seat**. Key it to sail system. Every source agrees on which control affects which *sail*; none agree on which *person* holds it. This is the strongest single argument for the by-sail-system panel.

One thing all sources converge on: **power controls cluster** (mainsheet + traveller + backstay are consistently held by one person, S5, S2), and **set-and-forget controls cluster** (vang, outhaul, cunningham, halyards — bow's job, S2). That's a natural primary/secondary split inside a panel.

### 2.2 The control set

**Mainsail system**

| Control | Changes | Primary use | Up/Down | Gear order |
|---|---|---|---|---|
| Backstay | Bends mast → flattens main, opens upper leech; *also* tensions headstay → flattens jib (S1) | Master depower | Both (75–100% planing, off soak, S15) | **First** significant depower, applied *before* the puff (S9, S10) |
| Mainsheet | Leech tension → twist + angle of attack | Mode selection, played constantly for steady heel (S4) | Upwind primary | Continuous, not a gear |
| Traveller | Boom angle without changing twist | Heel management | Upwind | Max up <4kt → up 6" @10–12 → centred 18kt+ (S2) |
| Vang | Leech tension when sheet eased; low-section depth | Downwind primary leech control; upwind heavy-air low-leech flattening | Both | 0 → 25% → 80% → 100% across range (S2) |
| Outhaul | Foot depth | Lowest-impact depower, so used **first** in the generic ladder (S8) | Upwind | Eased 2" light → maxed heavy (S2) |
| Cunningham | Draft position forward (S17) | Fine, heavy-air | Upwind | Progressive with wind (S8) |
| Main halyard | Full hoist to the white band; check for stretch (S1) | Setup, not a gear | — | Pre-race |

**Headsail system**

| Control | Changes | Primary use | Gear order |
|---|---|---|---|
| Jib sheet | Angle of attack + leech tension | Continuous | Ease **first** when overtrimmed (S12) |
| Jib lead (car) | Fwd = tighter leech, rounder foot; aft = open leech, flatter foot (S1) | "The foundation for all other adjustments" (S12) | **Second** — move aft to add twist (S12); 4 holes light → 6 base → 7 at 26kt+ (S2) |
| Inhauler | Clew inboard → deepens lower jib, closes leech, narrows sheeting angle (S1, S3) | Pointing | Conservative; ~1" limit or groove gets narrow (S13); moving inhauler aft requires lead forward (S3) |
| Jib halyard | Luff tension → draft position, entry | Trimmable underway | Light: slight wrinkles 4–8" back from luff; heavy: wrinkles gone (S1, S12) |

**Rig system** (dock-set, not sailed)

Forestay length/rake — longer rake = more weather helm + pointing, better light air; shorter = less helm, better heavy air (S2). Base 56–58" depending on source. Uppers control headstay tension and upper mast; lowers control prebend and mid-mast (S14). Target prebend 2–2.5". Turns from base scale with wind: −7/−4 at 0–4kt to +8/+6 at 26kt+ (S2).

**Downwind**: tackline (ease 4–5" to rotate luff to weather in soak, S3), kite sheet, vang (eased for twist in soak, on for wing-on-wing stability, S15), crew fore-aft (forward in displacement → behind the winch at 20kt, S3), backstay (off soaking, 75–100% planing, S15).

### 2.3 Feedback cues — and what a simulator can actually render

| Cue | Source | Renderable? |
|---|---|---|
| Main leech ribbon stall % (50–70% max trim; 100% building speed) | S1, S3 | **Yes** — the single best trim-quality readout. Render as a stall-percentage meter, not a binary. |
| Jib luff telltales; leeward one "nervous" | S4 | **Yes**, but "nervous" is a temporal texture — needs animation, not a static state |
| Jib upper leech telltales 90–100% flow | S12 | **Yes** |
| Top batten angle vs boom; mid parallel, lower slightly hooked | S13, S2 | **Yes** — geometric, cheap to draw |
| Jib leech vs spreader stripe (18/20/22") | S1, S2 | **Yes** — a discrete, readable number. Strong candidate for the headsail panel's primary visual |
| Inversion wrinkles in main mid-section under backstay | S4 | **Yes** as a rendered threshold indicator; hard as literal cloth simulation |
| Foot-to-boom gap 4–7" | S1 | Yes |
| Heel angle (10° heavy, 10–15° planing) | S2, S3 | **Yes** — trivially |
| Helm load / feel | S3 | **Partially.** Force-feedback absent; render as a load bar. S3's key insight: helm load is only diagnostic *if heel is constant* — so the two must be shown together or the cue lies |
| Speed vs target | S19 | **Yes** — S19 argues for **% of polar** as one stable number over speed-vs-target pairs |
| Boat-on-boat, "netting out fast forward" | S3, S11 | **Weakly.** Needs an AI tuning partner; a bearing-change indicator on one reference boat is the minimum viable version |
| Headstay sag (~0.5" mid-mast leeward in light air) | S3 | Yes, if the rig model carries sag |
| Bouncy headstay = uppers loose | S14 | Only with a dynamic rig model — likely out of scope |

**The honest gaps**: helm load through the hands, water texture/waves telling you which mode to pick, and fleet-relative speed. Everything else in the expert cue set is renderable.

### 2.4 Coaching frameworks

**North U (Gladstone) — the one to build on (S6, S7).** Three power sources: angle of attack, depth, twist. Sequence: *get to full power first, then adjust the mix.* Every J/70 control maps cleanly onto one of the three, which gives the trainer a defensible abstraction layer above the raw control list.

**Depth / twist / entry (S17).** Sail-section vocabulary: entry shape, max draft position (40–45%, or 45–50% with a jib), exit/leech shape. This is the *visual* complement to North U's *conceptual* model.

**The Five Essentials (RYA)** — course, trim, balance, sheeting, board. Beginner-level dinghy framework. Two of five don't apply to a keelboat. **Weak fit for a J/70 trainer** beyond an entry-level tutorial mode. Flag as thin.

**Depower ladder (S8)**: outhaul → vang → traveller → cunningham → luff → board → rig. Note this is a *dinghy* ladder and contradicts J/70 practice, where backstay is the master control and outhaul is barely a gear.

**Sequencing beginner → expert** (synthesised, moderate evidence): sources implicitly teach in this order — (1) telltales and angle of attack; (2) heel angle constancy; (3) twist via sheet/traveller; (4) depth via backstay/outhaul; (5) modes and gear-shifting; (6) rig tune. Keane's "sail by the numbers" grid (S16) is the expert endpoint: *stop feeling, start recalling settings.* That's a legitimate trainer end-state — a settings-grid recall drill.

### 2.5 Visualisations sailors already use

- **Sail cross-section stacks** with draft stripes — entry / max-draft-% / exit at three heights (S17). Universally taught.
- **Leech profile / batten angle** against boom centreline (S13).
- **Spreader stripes** — 18/20/22" — an in-situ analogue ruler for jib leech position (S1, S2).
- **Rig side elevation** showing rake and prebend as dimensioned measurements (S1, S2).
- **Wind-range gear chart** — the single most-used artefact in the sport: a table, wind on one axis, every control down the other (S2). Keane's grid (S16) is this.
- **Polar / % target** (S19).
- **Puff response flowcharts** — S9's three-region model is the closest published thing to a real flowchart.

## 3. Recommended panel grouping

The four-panel by-sail-system split is defensible, with one adjustment: **Rig should be modally separate** (dock/pre-race), not a peer of the live trim panels.

### Panel 1 — Mainsail
- **Controls:** mainsheet, traveller, backstay, vang, outhaul, cunningham, main halyard (setup-only, collapsed)
- **Primary visual:** main leech with **stall-percentage ribbon meter** at the top batten + top-batten angle relative to boom. Secondary: main cross-section stack (draft depth + position).
- **Coaching cue:** *"Leech ribbons stalling half the time is right; flowing all the time means you're building speed."* (S1, S3)
- **Rationale:** every source lists these together, and S5 confirms sheet+traveller+backstay live in one pair of hands.

### Panel 2 — Headsail
- **Controls:** jib sheet, jib lead position, inhauler, jib halyard
- **Primary visual:** **spreader-stripe leech gauge** (18/20/22") with luff telltale pair animated. Secondary: jib cross-section showing entry shape and clew inboard-distance from cabin house.
- **Coaching cue:** *"Trim until the top leech ribbon just stalls, then ease a hair — if it keeps stalling, lead aft."* (S12)
- **Rationale:** S12's explicit three-step priority (ease → lead aft → reduce tension) is a ready-made in-panel guided sequence.

### Panel 3 — Rig (mode-gated: dock/pre-race)
- **Controls:** upper shroud turns, lower shroud turns, forestay length / rake, prebend readout
- **Primary visual:** **rig side elevation** with dimensioned rake and prebend, plus a wind-range gear chart highlighting the current row.
- **Coaching cue:** *"Set it on the dock for the day's breeze — uppers hold the headstay, lowers set the prebend."* (S14)
- **Rationale:** Backstay is *not* here despite tensioning the headstay — it belongs to Mainsail because that's where the hand is. Show the cross-effect as a live headstay-sag indicator on the Headsail panel instead.

### Panel 4 — Helm + Conditions
- **Controls:** steering angle, crew fore-aft and athwartships position, mode selector (high / VMG / fast; downwind: plane / marginal / soak / wing / VMG)
- **Primary visual:** **combined heel-angle + helm-load gauge, side by side**, plus a single **% of polar target** number (S19).
- **Coaching cue:** *"Hold heel constant — helm load only tells you the truth when heel isn't moving."* (S3)
- **Rationale:** S3's point that heel variance corrupts the helm-feel signal makes co-locating these two gauges a correctness requirement, not a layout preference.

### Cross-panel: a puff-response overlay
S9/S10 both describe puff response as a *sequence across panels* (body → sheets → angle). This can't live in one panel. Recommend a transient overlay that lights the panels in order when a puff arrives, with the sequence chosen by power state (underpowered / transition / overpowered).

## 4. Contradictions between sources

1. **Who trims the main upwind.** North Sails Speed Guide (S3): the helm. Sailing World (S5), Quantum (S2), Duncan's team (S18): a dedicated main trimmer or tactician. → Don't bind panels to seats.
2. **Base rig numbers.** North (S1): uppers 19 / lowers 9, rake 56.5". Quantum (S2): uppers 22 / lowers 14, rake 58". Class-site search result: rake 56". These are *different gauge/measurement conventions and different sail designs* — not reconcilable. → Make rig baseline a selectable sailmaker preset; never hardcode one.
3. **Main leech telltale target.** North (S1, S3): stalling 50–70% at max trim. Quantum (S2): 80% flying in light, 50–75% stalling in medium, 100% flow in high wind — Quantum makes it wind-dependent where North makes it mode-dependent. S11 cites 80% vs 50% as high-vs-VMG. → Show a *band*, not a point target, and label whether the driver is wind or mode.
4. **Depower order.** SailZing's dinghy ladder (S8) puts outhaul first and backstay last. J/70 practice (S1, S2, S4) makes backstay the master and treats outhaul as minor. → Use the J/70-specific ordering.
5. **"Ease, hike, trim."** SailZing (S9) teaches it with variations; Ingham (S10) calls it a fallacy and says hikers should already be out. → Implement S10's condition-specific sequences; they subsume S9.
6. **Jib lead in heavy air.** North (S1): move leads aft to twist and depower. Quantum (S2): 6 holes at both 10–12 and 18–20kt, only going to 7 at 26+. → Low confidence either way.
7. **Inhauler aggression.** S3 counsels conservatism; S13 caps at ~1"; S1 wants the jib foot touching the cabin house "as much as possible". → Genuine disagreement about the pointing/groove trade-off. Worth modelling as an explicit trade-off the trainer teaches.
