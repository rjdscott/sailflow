# 01. Adversarial review of `docs/initial-prompt.md`

Reviewer stance: skeptical VPP engineer and product lead. Sources verified:
[ORC VPP Documentation 2023](https://orc.org/uploads/files/ORC-VPP-Documentation-2023.pdf)
(full text), [J/70 Class Rules 2025](https://j70ica.org/wp-content/uploads/2025/03/Class-Rules-2025.pdf),
[J/70 ORC Speed Guide](https://www.carpediemsailingteam.com/app/download/16137868/Speed_Guide_J70_Class.pdf),
[ORC OD certificate](https://data.orc.org/public/od/2021/j70.od.html?nav=1).

## Verified facts

- ORC VPP Documentation is public and implementable: Table 5.1 mainsail, 5.4
  genoa, 5.6–5.8 spinnakers (asym on centreline `kpasp 0.02648`, CL/CD at 12
  AWAs), depowering §5.1.3 (Fig 5.4), twist function §5.4.4, windage Table 5.10.
- **ORC sail model has no rig-tune input.** §5.1.1: a sail is area, CE height,
  CLmax/CD0 vs AWA envelope. Tune enters only as `flat`/`reef` scalars and a
  discrete Low/Medium/High coefficient set by rig adjustability (§5.1.2,
  Table 5.2). No draft depth, draft position, entry/exit angle, or per-height
  twist anywhere in the input path.
- J/70 C.9.5 wording correct (2025 CR): forestay/shrouds/backstay legs not
  adjusted whilst racing; backstay control line permitted; forestay not
  adjusted from leaving dock until finished racing for the day. 2026 CR
  effective 2026-02-01 exists; sub-rule number unverified for that edition.
- The J/70 Speed Guide was generated by "VPP 2011 1.02", issued 2012. ORC
  single-sail coefficients last adjusted 2016; depowering overhauled 2023
  (min flat → 0.42, PHI_UP deleted, effective rig height raised, twist effect
  increased). Any fit of a 2023-model implementation to that polar carries
  ORC's own revisions in the residual.
