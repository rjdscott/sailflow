# Research

Analysis workspaces: the reading, benchmarking, and comparison that happens
*before* a decision is made. Freeform inside, dated outside.

## Conventions

- One directory per investigation: `<YYYY-MM-DD>-<slug>/`, with a `README.md`
  stating the question, and numbered files (`01-...`, `02-...`) so reading
  order is obvious.
- Research holds analysis, not decisions and not procedures. The moment a
  conclusion turns into a commitment it becomes an ADR (`../adr/`); ADRs,
  plans, and audits cite research rather than restating it.
- Research is allowed to be wrong in hindsight. Don't rewrite it to match what
  was eventually decided; the ADR is what carries the verdict.
